# TicTacToe game with PYTHON
I used Python built-in libraries to make this tic tac toe game.
## HOW TO PLAY
* Click on the boxes with your mouse to write "X".
* Computer will randomly choose a box and write "O".
* You win if "X" forms a row of three vertically, horizontally or diagonally.
## HOW TO RUN
* Make sure you have **Python** installed on your computer.
* Download all files in this repository to the same folder.
* Open your terminal in that folder and run:
```bash
python tictactoe.py
```
